🤔რატომ გჭირდებათ

ლექცია 3-ზე მოდელმა ტექსტიდან ჯავშანი ამოიღო, მაგრამ ვერ გვითხრა, თავისუფალია თუ არა მაგიდა: ჩვენს ბაზას ვერ ხედავს და ან იგონებს, ან უარს ამბობს. დღეს მოდელს ვაძლევთ tool-ებს, ჩვენს C# მეთოდებს: მოდელი ითხოვს გამოძახებას, ჩვენი კოდი ასრულებს, და პასუხი ჩვენი ბაზის ნამდვილ მონაცემზე დგება. ეს არის ყველა AI ასისტენტისა და აგენტის საფუძველი.

🎯ლექციის ბოლოს შეძლებთ

  • ახსნი function calling-ის ციკლს: tool-ების სია → გამოძახების თხოვნა → ჩვენი კოდი ასრულებს → შედეგი → პასუხი

  • UseFunctionInvocation-ით ციკლს ავტომატურად ატრიალებ და AssistantController-ში tool-ებს ChatOptions.Tools-ით გადასცემ
  • დაწერ კარგ tool-ს: ზმნა-სახელი, აღწერა, ტიპიზებული პარამეტრები; ახსნი, რატომ არის დღეს tool-ები მხოლოდ კითხვისთვის

Tools/TableTools.cspublic record AvailabilityInfo(bool Available, int FreeTables); public sealed class TableTools(DataContext db){    [Description("Checks whether a table is free at the given time")]    public async Task<AvailabilityInfo> CheckAvailability(        [Description("Booking date and time")] DateTime at,        [Description("Number of guests")] int guests    )    {        var from = at.AddHours(-2);        var to = at.AddHours(2);         var free = await db.Tables.CountAsync(t =>            t.Seats >= guests &&            !db.Bookings.Any(b => b.TableId == t.Id && b.At > from && b.At < to)        );         return new AvailabilityInfo(free > 0, free);    }}
