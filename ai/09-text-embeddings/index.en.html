Let's recall: Error Handling, Resilience and Cost Control

1Which error does retry help with, and which doesn't it? One example each.Transient — 429, 500/503, timeout, the network: trying again helps · permanent — 400, 401, 403, 404: the same request brings the same error · content (length, bad JSON) — in code
2Why don't we retry 10 times right away? What are backoff and jitter?We'd send an overloaded service even more requests · backoff — a growing pause (2→4→8 s) · jitter — a random part, so many clients don't retry at the same time · on a 429 — Retry-After
3Why do we turn off Google.GenAI's own retry?Retry must be in one place · two nested retries = 4 × 4 = 16 attempts and minutes of waiting · HttpRetryOptions { Attempts = 1 } + our HttpClient through ClientOptions.HttpClientFactory
4Where does FallbackChatClient stand in the pipeline, and which errors does it catch?Innermost (the last .Use) — every request of the tool loop gets its own fallback · only transient ones: ApiException 429/5xx, the network, a timeout · catch … when
5Why does TokenCounter get the DbContext through IServiceScopeFactory to write to the database?The pipeline is a Singleton, the DbContext is Scoped · injecting it directly = a captive dependency · the layer creates its own scope every time

Today's topic

Text Embeddings: Vectorizing Text

🤔Why you need this

“Something light, without meat” — sending the whole menu is expensive, and LIKE won't find the lobio, because those words aren't in its description. Today we learn about embeddings: turning text into a vector where a similar meaning is close together. This is the foundation of semantic search, RAG and agent memory — the whole second half of the module stands on it.

  • You'll write the question and the document with the right task prefix and explain why the search is asymmetric

📐 Cosine similarity · the angle between two arrows

What points in the same direction is similar

by hand — how it's calculatedstatic float Cosine(ReadOnlySpan<float> a, ReadOnlySpan<float> b){    float dot = 0, na = 0, nb = 0;    for (int i = 0; i < a.Length; i++)    {        dot += a[i] * b[i];        na  += a[i] * a[i];        nb  += b[i] * b[i];    }    return dot / (MathF.Sqrt(na) * MathF.Sqrt(nb));}      
the same, in one line (SIMD)float score = TensorPrimitives.CosineSimilarity(a.Span, b.Span);
1 — the same direction · 0 — nothing in common. The number depends on the model: we compare, we don't read it on its own

1Why doesn't LIKE find the lobio for “without meat”, and what does an embedding do differently?LIKE looks for words, and those words aren't in the description · an embedding turns the text into a vector where a similar meaning is close — regardless of language and words
2How is an embedding model different from a chat model? Which one do we use and at what size?It doesn't write text — it returns one vector, and only the input is charged · IEmbeddingGenerator · gemini-embedding-2, 768 dimensions
3Why can't we “just” change the model if vectors are already stored?Every model (and size) has its own “map” — vectors from different models can't be compared · changing the model = calculating every vector again
4What is a task prefix, and why do the question and the document have different ones?Asymmetric search: a short “wish” ↔ long “facts” · task: search result | query: … and title: … | text: … · always by the same rule
5What does cosine similarity measure, and how do we read the number?The angle between two vectors: 1 — the same direction, 0 — nothing in common · the number depends on the model — we compare and sort, we don't judge it on its own
