🤔რატომ გჭირდებათ

„რამე მსუბუქი, ხორცის გარეშე“ — მთელი მენიუს გაგზავნა ძვირია, ხოლო LIKE ლობიოს ვერ იპოვის, რადგან ეს სიტყვები მის აღწერაში არ წერია. დღეს ვსწავლობთ embedding-ს: ტექსტის გადაქცევას ვექტორად, სადაც მსგავსი მნიშვნელობა ახლოსაა. ესაა სემანტიკური ძებნის, RAG-ისა და აგენტების მეხსიერების საფუძველი — მთელი მოდულის მეორე ნახევარი ამაზე დგას.

🎯ლექციის ბოლოს შეძლებთ

  • ახსნი, რა არის embedding და ვექტორი, რატომ არის მსგავსი მნიშვნელობა „ახლოს“ და რატომ არ შეედრება სხვადასხვა მოდელის ვექტორები
  • IEmbeddingGenerator-ს დაარეგისტრირებ (gemini-embedding-2, 768 განზომილება) და GenerateVectorAsync / GenerateAsync-ით ვექტორებს მიიღებ
  • შეკითხვას და დოკუმენტს სწორი task prefix-ით ჩაწერ და ახსნი, რატომ არის ძებნა ასიმეტრიული
  • cosine similarity-ს გამოთვლი (ხელით და TensorPrimitives-ით) და მენიუს სემანტიკურ ძებნას დაწერ top 3-ით

ხელით — როგორ ითვლებაstatic float Cosine(ReadOnlySpan<float> a, ReadOnlySpan<float> b){    float dot = 0, na = 0, nb = 0;    for (int i = 0; i < a.Length; i++)    {        dot += a[i] * b[i];        na  += a[i] * a[i];        nb  += b[i] * b[i];    }    return dot / (MathF.Sqrt(na) * MathF.Sqrt(nb));}
