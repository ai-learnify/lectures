Today's topic

Streaming and Real-time AI Responses

🤔Why you need this

Until now our endpoints returned the answer whole: the user stared at an empty screen for 2–8 seconds. Every modern AI chat shows the answer as it's being written. Today we get the answer from Gemini in pieces, send it to the client right away with Server-Sent Events, and add cancellation — so we don't pay for Gemini's tokens after the user has left. Without this skill an AI chat doesn't look like a product.

🎯By the end of the lecture you can

  • You'll explain what streaming changes (TTFT) and what it doesn't (the total time)
  • You'll get the answer piece by piece with GetStreamingResponseAsync and await foreach, and measure when each piece arrives
  • You'll write an SSE endpoint with TypedResults.ServerSentEvents and an async iterator (yield return), and check it with curl -N
  • You'll pass a CancellationToken in three places so that the Gemini request stops when the client leaves

Controllers/AssistantController.cs · ChatStream[HttpGet("chat/stream")]public IResult ChatStream(string message, CancellationToken cancellationToken){    return TypedResults.ServerSentEvents(StreamAnswer(message, cancellationToken));} private async IAsyncEnumerable<string> StreamAnswer(string message,    [EnumeratorCancellation] CancellationToken cancellationToken){    List<ChatMessage> messages = [SystemPrompt(), new(ChatRole.User, message)];     await foreach (ChatResponseUpdate update in        _chat.GetStreamingResponseAsync(messages, CreateChatOptions(), cancellationToken))    {        if (!string.IsNullOrEmpty(update.Text))            yield return update.Text;    }}

1Does streaming make the answer faster? What actually changes?The total time is almost the same · what changes is the TTFT — the time to the first word (seconds → milliseconds) · the user starts reading right away, no more empty screen
2What does GetStreamingResponseAsync return and how do we read it?An IAsyncEnumerable<ChatResponseUpdate> — a stream of pieces · await foreach — waits for the next piece · update.Text — a chunk of text; the same messages/options, tools work too

4What is SSE and why is it enough for an AI chat (instead of WebSocket/SignalR)?An HTTP response with text/event-stream that stays open; data: … + an empty line · an AI answer is one-way (server → client) · WebSocket/SignalR are for two-way communication
