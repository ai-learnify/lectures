Simple RAG: Answers from Documents

🎯 After this lecture you can

  • You'll explain RAG's two pipelines (ingestion and query) and why it beats the whole document in the context and fine-tuning
  • You'll extract text from a PDF page by page (PdfPig), cut it into parts with an overlap, and store the parts with vectors in a DocumentChunk table
  • You'll find the parts relevant to a question with a threshold and put them into the prompt as numbered sources
  • You'll plug RAG into lecture 7's chat: an answer with the source number, “I don't have information”, the original question in the history

⚡ Key points

  1. RAG = retrieve → augment → generate: the model answers from the parts of our documents we found, and names the source.
  2. Two pipelines: ingestion once (PDF → text → chunks → vectors → database) and query on every question.
  3. Chunk = one idea (~800 characters, with overlap). We keep the page to cite the source.
  4. A threshold and rules in the prompt: "I don't have that information" instead of making things up.
  5. The history keeps the original question. The sources go only into this request.

The idea of RAG

▶ Slides 6–8

The restaurant has a rules PDF: cancelling a booking, allergens, pets. The model does not know it.

Option Problem
The whole PDF in the prompt expensive and slow on every question; in a big text the model finds details worse
Fine-tuning expensive and slow; it teaches facts poorly, and the rules will change
RAG only the parts needed for each question

Retrieve: find the relevant parts. Augment: put them into the prompt. Generate: the model answers based on them.

✅ Check yourself think first, then open the answer
What happens once and what on every question?
Once: ingestion, the document goes into the database as chunks and vectors. Every question: query, search, insert into the prompt and answer.

RAG (Retrieval-Augmented Generation)

Ingestion: a document into the database

▶ Slides 9–12

PDF → text. A PDF contains letters and their coordinates, not words. PdfPig assembles them into text page by page:

Ai/PdfText.cs
using System.Text.RegularExpressions;using UglyToad.PdfPig;using UglyToad.PdfPig.DocumentLayoutAnalysis.TextExtractor; public static class PdfText{    public static List<(int Page, string Text)> ReadPages(byte[] pdf)    {        using PdfDocument doc = PdfDocument.Open(pdf);        return doc.GetPages()            .Select(p => (p.Number, Clean(ContentOrderTextExtractor.GetText(p))))            .Where(p => p.Item2.Length > 0)          // skip empty pages            .ToList();    }     private static string Clean(string text) =>        Regex.Replace(text, @"\s+", " ").Trim();     // extra spaces and line breaks}
⚠️

A scanned PDF (photos) contains no text and returns nothing. It needs OCR.

Chunking. A whole document as one vector is vague; a single sentence loses its context. We cut ~800 characters, at sentence boundaries, with overlap:

Ai/TextChunker.cs
public static class TextChunker{    public static List<string> Split(string text, int maxChars = 800, int overlap = 1)    {        string[] sentences = Regex.Split(text, @"(?<=[.!?])\s+");        List<string> chunks = [];        List<string> current = [];         foreach (string sentence in sentences)        {            if (current.Count > 0 && current.Sum(s => s.Length) + sentence.Length > maxChars)            {                chunks.Add(string.Join(" ", current));                current = current.TakeLast(overlap).ToList();   // overlap: the last sentence stays            }            current.Add(sentence);        }        if (current.Count > 0)            chunks.Add(string.Join(" ", current));        return chunks;    }}

[HttpPost("documents")]public async Task<IActionResult> UploadDocument(IFormFile file, CancellationToken ct){    using var ms = new MemoryStream();    await file.CopyToAsync(ms, ct);     // 1–2: PDF → pages → parts    var doc = new Document { FileName = file.FileName, UploadedAt = DateTime.UtcNow };    foreach (var (page, text) in PdfText.ReadPages(ms.ToArray()))        foreach (string chunk in TextChunker.Split(text))            doc.Chunks.Add(new DocumentChunk { Page = page, Content = chunk });     // 3: vectors, in batches of 100    string model = _config["Gemini:EmbeddingModel"]!;    foreach (DocumentChunk[] batch in doc.Chunks.Chunk(100))    {        var vectors = await _embeddings.GenerateAsync(            batch.Select(c => EmbeddingText.Document(doc.FileName, c.Content)),            cancellationToken: ct);        for (int i = 0; i < batch.Length; i++)        {            batch[i].Embedding = new Vector(vectors[i].Vector);            batch[i].EmbeddingModel = model;        }    }     // 4: into the database — the document and all its parts together    _db.Documents.Add(doc);    await _db.SaveChangesAsync(ct);    return Ok(new { doc.Id, Chunks = doc.Chunks.Count });}
✅ Check yourself think first, then open the answer
What if a chunk were one sentence?
The vector would be precise but the context would be lost: the model would get "this rule applies…" without knowing which rule.

Query: an answer with a source

▶ Slides 14–16

Retrieve: lecture 10's search, but over chunks, with 5 results and a threshold:

Controllers/AiLabController.cs · SearchChunksAsync
public record FoundChunk(string File, int Page, string Content, double Score); private async Task<List<FoundChunk>> SearchChunksAsync(string q, CancellationToken ct){    float minScore = _config.GetValue<float>("Rag:MinScore");   // by testing — like lecture 9's homework    var query = new Vector(await _embeddings.GenerateVectorAsync(        EmbeddingText.Query(q), cancellationToken: ct));     List<FoundChunk> top = await _db.DocumentChunks        .Where(c => c.Embedding != null)        .OrderBy(c => c.Embedding!.CosineDistance(query))        .Select(c => new FoundChunk(c.Document.FileName, c.Page, c.Content,            1 - c.Embedding!.CosineDistance(query)))        .Take(5)        .ToListAsync(ct);     return top.Where(c => c.Score >= minScore).ToList();}

✅ Check yourself think first, then open the answer
Why don't we store the augmented message in the history?
The sources belong to this question. They would bloat the history, and the next question finds new sources.
"A borscht recipe". What happens if the document does not mention it?
Because of the threshold no source is found, and by the rules the model says "I don't have that information".

💡 If you get stuck

  • The PDF is empty (0 parts)? It's a scan or a photo — Word/Google Docs → Save as PDF
  • The Georgian text is “garbage”? An old font — export again with a Unicode font (Sylfaen, Noto Sans Georgian)
  • IFormFile doesn't show as a file in Swagger? The parameter IFormFile file — in an [ApiController] it's recognized as a form
  • c.Document.FileName is null? A navigation in Select is translated into a JOIN in SQL — you don't need Include
