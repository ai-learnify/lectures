Simple RAG: პასუხი დოკუმენტებიდან

🎯 ამ ლექციის შემდეგ შეძლებ

  • ახსნი RAG-ის ორ pipeline-ს (ingestion და query) და რატომ სჯობს ის მთელ დოკუმენტს კონტექსტში და fine-tuning-ს
  • PDF-დან ტექსტს გვერდებით ამოიღებ (PdfPig), ნაწილებად დაჭრი overlap-ით და ნაწილებს ვექტორებით Chunk ცხრილში შეინახავ
  • შეკითხვაზე რელევანტურ ნაწილებს ზღვრით იპოვი და prompt-ში გადანომრილ წყაროებად ჩასვამ
  • RAG-ს ლექცია 7-ის ჩატში ჩართავ: პასუხი წყაროს ნომრით, „ინფორმაცია არ მაქვს“, ისტორიაში — ორიგინალი შეკითხვა

⚡ მთავარი

  1. RAG = retrieve → augment → generate: მოდელი პასუხობს ჩვენი დოკუმენტების ნაპოვნი ნაწილებით და წყაროს ასახელებს.
  2. ორი pipeline: ingestion ერთხელ (PDF → ტექსტი → ნაწილები → ვექტორები → ბაზა) და query ყოველ შეკითხვაზე.
  3. chunk = ერთი აზრი (~800 სიმბოლო, overlap-ით). გვერდს წყაროს მისათითებლად ვინახავთ.
  4. ზღვარი და წესები prompt-ში: „ინფორმაცია არ მაქვს“ მოგონების ნაცვლად.
  5. ისტორიაში ორიგინალი შეკითხვა ინახება. წყაროები მხოლოდ ამ მოთხოვნაში მიდის.

📍 ლექცია გააცდინე?

  1. ნახე პრეზენტაცია: სლაიდები ლექციის მთელ გზას აჩვენებს
  2. წაიკითხე თემები: ~9 წთ, თითოს ბოლოს „შეამოწმე თავი“
  3. გაიარე ტესტი: 8 კითხვა
  4. გააკეთე დავალებები

Chunking. მთელი დოკუმენტი ერთ ვექტორად ბუნდოვანი გამოვა, ერთი წინადადება კი კონტექსტს კარგავს. ვჭრით ~800 სიმბოლოდ, წინადადების საზღვარზე, overlap-ით:

Ai/Documents/TextChunker.cs
public static class TextChunker{    public static List<string> Split(string text, int maxChars = 800, int overlap = 1)    {        string[] sentences = Regex.Split(text, @"(?<=[.!?])\s+");        List<string> chunks = [];        List<string> current = [];         foreach (string sentence in sentences)        {            if (current.Count > 0 && current.Sum(s => s.Length) + sentence.Length > maxChars)            {                chunks.Add(string.Join(" ", current));                current = current.TakeLast(overlap).ToList();   // overlap: the last sentence stays            }            current.Add(sentence);        }        if (current.Count > 0)            chunks.Add(string.Join(" ", current));        return chunks;    }}
