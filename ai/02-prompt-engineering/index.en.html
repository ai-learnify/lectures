Let's recall: Introduction to Generative AI and LLM APIs

1What is a token and why do we care about it in the backend?a piece of text the model reads and writes in · price, the context window limit and speed are counted in tokens; Georgian — more tokens
2How does an LLM write an answer?next-token prediction: computes probabilities for the next token → picks one → appends it → repeats until it finishes or hits the limit
3The model named the price of our dish. Why don't we trust it?it has never seen our menu; it writes what's likely, not what's true — hallucination · prices always come from the database
4Why doesn't the model “remember” the previous request?stateless: every request is independent · we have to send the history every time
5Which Temperature do we set to detect the order type, and what does finish_reason = length mean?0 — one correct answer, the same every time (on Gemini 3 — the default, lecture 2) · length — it hit Max Tokens, the answer was cut off
6The restaurant chat has 300 conversations a day. What increases the cost the most?an expensive model (prices differ tenfold) · a growing history that is sent again every time · Georgian text — more tokens

Let's check

5 questions

1What is IChatClient, and what do we change to switch from Gemini to another provider?one interface for every chat model (Microsoft.Extensions.AI) · only the line that creates the client changes; GetResponseAsync, the DTOs and the endpoints stay the same
2With maxOutputTokens: 15 the answer is empty and finishReason = length. Why?Gemini “thinks” before answering · the thinking tokens (ReasoningTokens) count toward the same limit and nothing is left for the answer · set the limit with room to spare
3How is a System message different from a User message?we write the System message in code: role, topics, rules, answer format · the User message is written by the user · Assistant — the model's answer
4What is few-shot and when do we need it?a few “question → correct answer” examples in the prompt · when we want the answer in an exact format or exact categories so the code can use it
5The system prompt says: “You never name a price”. Is that a guarantee?no · a prompt changes the probability of a behaviour but gives no guarantee · what must hold is checked by C# code (lecture 19)
