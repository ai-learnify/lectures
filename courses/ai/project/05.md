### ლექციაზე
- **ერთად წერთ:** `.UseLogging()` + ლოგის დონე, `TokenCounterChatClient` და მისი რეგისტრაცია.
- **ვცდით და ვაშორებთ:** `UseDistributedCache` — იგივე კითხვა მეორედ Gemini-ს გარეშე (4 ms). შემდეგ კლასთან ერთად: „ხვალ 8-ზე მაგიდა გაქვთ?“ — ქეში ძველ პასუხს დააბრუნებს, ამიტომ ჩატის pipeline-ში ქეში **არ** რჩება.
- **ჩასვამ და ახსნი:** `InputGuardChatClient` და საბოლოო რიგი.
- **წინასწარ:** ორივე ფენა და საბოლოო pipeline შენთან მუშაობს.

```note
Controller ამ ლექციაზე **არ** იცვლება — ეს არის ლექციის მთავარი აზრი: ყველაფერი `Program.cs`-ის pipeline-ში ემატება.
```

### რიგი pipeline-ში
`.Use…()`-ების თანმიმდევრობა = Controller-იდან Gemini-მდე. პირველი — გარე ფენა (Controller-თან ახლოს), ბოლო — შიდა (Gemini-სთან ახლოს).

| # | ფენა | რატომ აქ |
|---|---|---|
| 1 | `InputGuardChatClient` | ყველაზე ადრე აჩერებს — გრძელი შეკითხვა tool-ების ციკლშიც არ შედის |
| 2 | `UseFunctionInvocation` | tool-ების ციკლი: ერთი შეკითხვა → რამდენიმე მოთხოვნა |
| 3 | `TokenCounterChatClient` | ციკლის **შიგნით** — ყოველ Gemini-მოთხოვნას ცალკე ითვლის (ვარიანტი B) |
| 4 | `UseLogging` | Gemini-სთან ყველაზე ახლოს — ლოგში ზუსტად ის ჩანს, რაც გაიგზავნა |

### შემოწმება
- `/chat` `"How much is lobio?"` → ლოგში ორი მოთხოვნა (tool call + საბოლოო პასუხი) და ორი `🔢` ხაზი.
- 1000 სიმბოლოზე გრძელი prompt → `"The question is too long — 1000 characters at most."`, ლოგში Gemini-ს მოთხოვნა არ ჩანს.

### ქეშის ცდა (pipeline-ში არ რჩება)

ლექციაზე ქეში საცდელად ემატება (ორი ხაზი) და, „ხვალ 8-ზე“-ს მაგალითის შემდეგ, იშლება:

```csharp Ai/TokenCounterChatClient.cs
using Microsoft.Extensions.AI;

public class TokenCounterChatClient : DelegatingChatClient
{
    private readonly ILogger<TokenCounterChatClient> _logger;

    public TokenCounterChatClient(IChatClient inner,
        ILogger<TokenCounterChatClient> logger) : base(inner)
    {
        _logger = logger;
    }

    public override async Task<ChatResponse> GetResponseAsync(
        IEnumerable<ChatMessage> messages,
        ChatOptions? options = null,
        CancellationToken cancellationToken = default)
    {
        // ↓ here is the request — it hasn't reached Gemini yet
        ChatResponse response =
            await base.GetResponseAsync(messages, options, cancellationToken);
        // ↑ here is the response — Gemini has already answered

        _logger.LogInformation("🔢 in: {In}, out: {Out}, total: {Total}",
            response.Usage?.InputTokenCount,
            response.Usage?.OutputTokenCount,
            response.Usage?.TotalTokenCount);

        return response;
    }
}
```

```csharp Ai/InputGuardChatClient.cs
using Microsoft.Extensions.AI;

public class InputGuardChatClient : DelegatingChatClient
{
    private const int MaxLength = 1000;

    public InputGuardChatClient(IChatClient inner) : base(inner) { }

    public override Task<ChatResponse> GetResponseAsync(
        IEnumerable<ChatMessage> messages,
        ChatOptions? options = null,
        CancellationToken cancellationToken = default)
    {
        string? question = messages.LastOrDefault(m => m.Role == ChatRole.User)?.Text;

        if (question is not null && question.Length > MaxLength)
        {
            ChatMessage answer = new(ChatRole.Assistant,
                $"The question is too long — {MaxLength} characters at most.");
            return Task.FromResult(new ChatResponse(answer));
        }

        return base.GetResponseAsync(messages, options, cancellationToken);
    }
}
```
