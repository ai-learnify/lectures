# ლექტორისთვის · ლექცია 9

სტუდენტები ამ გვერდს ვერ ხედავენ. სამი ეტაპი: **📖 ისწავლე** — თემის სრული ახსნა შენთვის; **🎯 მოემზადე** — როგორ ჩაატარო ლექცია: მსვლელობა, კითხვები, შეცდომები; **📋 ლექციაზე** — მოკლე გეგმა კლასში. თუ პრეზენტაცია ამ გვერდიდან გახსენი, მიმდინარე თემა მოინიშნება.

## 🎯 მიმოხილვა

ლექცია ლექცია 8-ის ბოლო კითხვით იწყება: „რამე მსუბუქი, ხორცის გარეშე“ — მთელი მენიუ ძვირია, LIKE ვერაფერს პოულობს. სამი ნაწილია.

**ნაწილი 1 — რა არის embedding (თეორია, კოდის გარეშე).** LIKE-ის პრობლემა ცოცხლად. „მნიშვნელობის რუკა“: ტექსტი → ვექტორი, მსგავსი = ახლოს, ენის მიუხედავად. ცალკე embedding მოდელი (`gemini-embedding-2`, 768), „ერთი მოდელი — ერთი რუკა“.

**ნაწილი 2 — ვექტორი კოდში.** `AddEmbeddingGenerator` + `AsIEmbeddingGenerator` — ლექცია 3-ის `AddChatClient`-ის ტყუპისცალი. `/embed` — 768 რიცხვი Swagger-ში. task prefix: შეკითხვა ≠ დოკუმენტი.

**ნაწილი 3 — მსგავსება და ძებნა (ლექციის მთავარი კოდი).** cosine similarity — კუთხე; ხელით loop და `TensorPrimitives`. მენიუს ინდექსი (ერთხელ) და ძებნა (top 3). შედეგი: LIKE — 0, embeddings — ლობიო, ბადრიჯანი, სალათი.

**ეს ლექცია მოდულის „გადახვევის“ წერტილია:** 10 (pgvector), 11–12 (RAG), 14+ (აგენტების მეხსიერება) — ყველაფერი ამაზე დგას. ამიტომ ინტუიცია („რუკა“, „ახლოს“) უფრო მნიშვნელოვანია, ვიდრე ფორმულა.

### 📌 სტუდენტს აუცილებლად უნდა დარჩეს

1. embedding: ტექსტი → ვექტორი; მსგავსი მნიშვნელობა = ახლოს (ენის მიუხედავად).
2. ცალკე მოდელი; ერთი მოდელი/ზომა = ერთი რუკა — შეცვლა = ყველაფრის თავიდან დათვლა.
3. `IEmbeddingGenerator`: `GenerateVectorAsync` / `GenerateAsync`.
4. task prefix: შეკითხვა და დოკუმენტი სხვადასხვა ფორმატით, ყოველთვის.
5. cosine similarity — კუთხე; ვადარებთ და ვალაგებთ, ციფრს ცალკე არ ვაფასებთ.

embedding მნიშვნელობას „კოორდინატებად“ აქცევს. როცა მნიშვნელობა კოორდინატებია, „მსგავსი“ ხდება „ახლოს“ — და ახლოს მყოფის პოვნა კომპიუტერს კარგად გამოსდის.

### 📖 ისწავლე: embedding-ის იდეა

#### საიდან მოდის „მნიშვნელობა“

embedding მოდელი (ჩვეულებრივ transformer, LLM-ის მსგავსი არქიტექტურა) ივარჯიშება მილიარდობით ტექსტის წყვილზე: „ეს ორი ტექსტი ერთსა და იმავეზეა“ (კითხვა ↔ პასუხი, სათაური ↔ სტატია, თარგმანი ↔ ორიგინალი) და „ეს ორი — არა“. ვარჯიშის მიზანი: მსგავსი წყვილის ვექტორები ახლოს, განსხვავებულის — შორს (contrastive learning). შედეგად მოდელი სწავლობს „მნიშვნელობის სივრცეს“. მრავალენოვან მონაცემებზე ვარჯიშის გამო ქართული და ინგლისური ერთსა და იმავე სივრცეშია.

#### ტოკენის ვექტორი vs ტექსტის ვექტორი

ლექცია 1-ში: LLM-ის შიგნით ყოველ ტოკენს ვექტორი აქვს (token embedding). embedding მოდელი **მთელ ტექსტს** ერთ ვექტორს აძლევს (ტოკენების ვექტორებიდან „შეკრებილს“). ჩატის მოდელის შიდა ვექტორები გარეთ არ გამოდის და ძებნისთვის არ არის გავარჯიშებული — ამიტომ ცალკე მოდელი.

#### `gemini-embedding-2`

- Stable; ტექსტი, სურათი, ვიდეო, აუდიო, დოკუმენტები — ერთ სივრცეში (multimodal); 100+ ენა.
- შეყვანა: 8 192 ტოკენამდე.
- გამოტანა: 128–3072, ნაგულისხმევად 3072; რეკომენდებული 768, 1536, 3072 (Matryoshka Representation Learning — ვექტორის დასაწყისი ნაწილიც „მუშაობს“, ამიტომ შეიძლება მოიჭრას).
- ტექსტურ ამოცანებზე Google task prefix-ს გვირჩევს.

#### რატომ 768

#### API

### 📖 ისწავლე: cosine similarity და ძებნა

#### ფორმულა

cos(θ) = (a · b) / (|a| × |b|), სადაც a · b = Σ aᵢbᵢ (სკალარული ნამრავლი), |a| = √Σ aᵢ² (სიგრძე).

- **normalized** ვექტორებზე (|a| = |b| = 1) cosine = dot product — ერთი ოპერაციით. Gemini-ს დოკუმენტაციით 3072 ნორმალიზებულია, სხვა ზომები — შეიძლება არა. cosine ამას თვითონ აგვარებს (სიგრძეზე ყოფს); dot product-ის გამოყენებამდე ნორმალიზაცია საჭიროა.
- **Euclidean distance** (L2) — „სწორი ხაზით მანძილი“; normalized ვექტორებზე იგივე დალაგებას იძლევა, რასაც cosine.
- ლექცია 10-ში pgvector-ის ოპერატორები: `<=>` — cosine **distance** (1 − similarity!), `<->` — L2, `<#>` — negative inner product. სტუდენტებს „distance ≠ similarity“ იქ დაუბნევს — დღეს ერთი წინადადებით შეგიძლია მოამზადო.

#### score-ების დიაპაზონი

[Description("Finds up to 3 menu dishes that match a description, e.g. 'something light without meat'.")]
public async Task<string> SearchMenu(
    [Description("What the guest wants, in their own words")] string query)
{
    ReadOnlyMemory<float> q = await _embeddings.GenerateVectorAsync(EmbeddingText.Query(query));
    var top = _menu.Items
        .Select(m => new { m.Name, Score = TensorPrimitives.CosineSimilarity(q.Span, m.Vector.Span) })
        .OrderByDescending(x => x.Score).Take(3).Select(x => x.Name);
    return string.Join(", ", top);
}
