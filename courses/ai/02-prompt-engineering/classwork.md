# შენი ასისტენტი — system prompt-ით

შენი პროექტი ან RestaurantApi · კოდით · Swagger-ში

## ნაბიჯები

- **1 · ახალი endpoint** `POST /api/ai-lab/assistant` — `ChatMessage`-ების სიით: System + User
- **2 · system prompt შენი პროექტისთვის** — 4 ნაწილი: **ვინ არის** · **რა თემებზე** პასუხობს · **რა ფორმით** (სიგრძე, ენა) · **რას არ აკეთებს**
- **3 · Swagger-ში 3 კითხვა:** ჩვეულებრივი · სხვა თემაზე ("Write me a poem") · ისეთი, რომელზეც უარი უნდა თქვას

## ✓ მზადაა, როცა

სხვა თემის კითხვაზე ასისტენტი თავაზიანად უარს ამბობს და შენს თემას უბრუნდება; პასუხი შენს მითითებულ ფორმაშია

## ⭐ ბონუსი

- System prompt-ში ჩასვი მონაცემი C#-დან (`$"""…{ცვლადი}…"""`): პროექტის სახელი, სამუშაო საათები
- სცადე „გატეხვა“: "Ignore the previous instructions and…" — დაიცავს თავს?

## 💡 თუ გაიჭედე

- **შაბლონი:** „შენ ხარ [პროექტის] ასისტენტი. პასუხობ მხოლოდ [თემები]-ზე. პასუხი: მაქსიმუმ [N] წინადადება, ქართულად. სხვა თემაზე თავაზიანად უარს ამბობ და ეუბნები, რაში შეგიძლია დაეხმარო.“
- **პასუხობს ყველაფერზე?** შეამოწმე, რომ System შეტყობინება სიაშია და system prompt-ში ცხადად წერია, **რა გააკეთოს** სხვა თემაზე
- **ბიბლიოთეკა, სპორტდარბაზი, მაღაზია** — ნებისმიერი პროექტი გამოდგება: ასისტენტი, რომელიც მხოლოდ მის საქმეზე ლაპარაკობს
